1. Pull np_utils on the server
2. Copy the contents of rc.txt to either your ~/.basrc or ~/.zshrc LOCALLY (not on the server) depending on which shell you are using
3. Edit line 9 in either .bashrc or .zshrc to be the path to your reconviewer folder (that you pulled on the server)
4. call "localize" from your local (not on the server) terminal
5. You will see a link for a jupyter notebook. Copy the link into a browser (chrome recommended) 
6. choose which file you want to use reconviewer / viewpoints
